# Sprache: Push-to-talk und Wake-Word „Jarvis“ (Stand 18)

## Entscheidung vom 01.11.2026 (Noah)
Die Roadmap-Regel „nur Push-to-talk, nie Dauerzuhören“ (Stufe 6.3) wird auf Noahs ausdrücklichen Wunsch so geändert:

- **Push-to-talk bleibt der Standard:** 🎙-Knopf halten oder Taste ⌥ (Option) halten. Nur dann ist das Mikrofon an.
- **Wake-Word „Jarvis“ ist zusätzlich möglich**, aber **standardmäßig AUS**. Einschalten im Chat: „Auf ‚Jarvis' hören“.
  Die Einstellung gilt nur in diesem Browser und lässt sich jederzeit ausschalten.

## Was dabei passiert (ehrlich)
- Die Spracherkennung macht der **Browser**: In Chrome geht der Ton zur Erkennung an Google, in Safari an Apple.
  **Firefox** hat keine Spracherkennung. Dort hilft die Mac-Diktierfunktion (zweimal `fn`).
- Bei eingeschaltetem Wake-Word hört der Browser **dauerhaft** zu, solange der Chat geöffnet ist.
- JARVIS speichert keine Tonaufnahmen. Erkannter Text wird wie getippter Text behandelt.
- Gesprochene Befehle können **nichts freigeben**. Freigaben gehen nur mit Häkchen und Passwort.
- Während JARVIS selbst spricht, werden erkannte Worte ignoriert, damit er sich nicht selbst antwortet.

## Bedienung
| Was | So geht's |
|---|---|
| Kurz etwas sagen | ⌥ halten, sprechen, loslassen → wird gesendet |
| Freihändig | Schalter „Auf ‚Jarvis' hören“ an → „Jarvis, was steht heute an?“ |
| Nur „Jarvis“ sagen | JARVIS antwortet „Ja, Sir?“ und nimmt den nächsten Satz (8 Sekunden) |
| Antworten hören | „Antworten automatisch sprechen“ einschalten |
